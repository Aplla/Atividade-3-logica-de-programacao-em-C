# Atividade 2 de lógica de programação em C

Projeto desenvolvido durante meus estudos iniciais de lógica de programação utilizando a linguagem C.

## Objetivo

Essa atividade teve como principal objetivo praticar conceitos fundamentais da programação em C, especialmente:

- Estruturas de repetição (`for`)
- Estruturas condicionais (`if`)
- Entrada e saída de dados
- Variáveis do tipo `float` e `int`
- Operações matemáticas
- Algoritmos de aproximação numérica

## Sobre o projeto

O programa calcula uma aproximação da raiz quadrada de um número informado pelo usuário utilizando o Método de Newton-Raphson (também conhecido como método babilônico).

Após receber um valor digitado pelo usuário, o algoritmo realiza 12 iterações para refinar o resultado até encontrar uma aproximação precisa da raiz quadrada.
